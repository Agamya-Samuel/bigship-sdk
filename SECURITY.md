# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 2.x | Yes |
| 1.x | No |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, email [security@agamya.dev](mailto:security@agamya.dev) with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

You should receive a response within 48 hours. We will work with you to understand the issue and coordinate a fix and disclosure timeline.

## Scope

This security policy applies to the `@agamya/bigship-sdk` npm package and this repository.

The SDK is intended for **server-side Node.js use only**. Do not expose Bigship credentials in browser or client-side applications.
