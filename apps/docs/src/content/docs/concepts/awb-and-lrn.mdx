---
title: AWB and LRN
description: Understanding Air Waybill (AWB) and Lorry Receipt Number (LRN) tracking identifiers in the Bigship SDK
---

Bigship uses two types of tracking identifiers depending on the shipment category: **AWB** for B2C and **LRN** for B2B.

## AWB (Air Waybill)

An AWB is the tracking number assigned to **B2C shipments** after manifestation. It uniquely identifies a parcel in the courier's network and is used for tracking and label generation.

```typescript
const place = await client.placeOrder({ MasterCustomOrderId: '311276742', courierId: 5, riskTypeId: '2' });
const details = await client.getOrderDetail('311276742');

// Track by order ID
const tracking = await client.trackOrder('311276742');
```

## LRN (Lorry Receipt Number)

An LRN is the tracking number assigned to **B2B shipments** after manifestation. It serves the same purpose as an AWB but for heavy/bulk shipments transported by road.

```typescript
const place = await client.placeOrder({ MasterCustomOrderId: '311276742', courierId: 25, riskTypeId: '2' });

// Track by order ID
const tracking = await client.trackOrder('311276742');
```

## Comparison

| Aspect | AWB | LRN |
|--------|-----|-----|
| **Shipment type** | B2C / B2B | B2B |
| **Assigned by** | `placeOrder` | `placeOrder` |
| **Retrieve with** | `getOrderDetail` | `getOrderDetail` |
| **Track with** | `trackOrder(orderId)` | `trackOrder(orderId)` |
| **Transport mode** | Air / surface (last-mile) | Road (heavy freight) |

## Tracking

The `trackOrder` method accepts the order ID:

```typescript
// B2C tracking
const b2cStatus = await client.trackOrder('311276742');

// B2B tracking
const b2bStatus = await client.trackOrder('311276743');
```
