---
title: Cancellation
description: Cancel one or more shipments by AWB number
---

Cancel shipments using the `cancelOrder` method. Pass the order ID to cancel an order (only before rider is assigned).

## Imports

```typescript
import {
  BigshipClient,
  isSuccessResponse,
} from '@agamya/bigship-sdk';
```

## Cancel Order

```typescript
const result = await client.cancelOrder('311276742');
if (isSuccessResponse(result)) {
  console.log('Order cancelled');
}
```

## Method Signature

```typescript
cancelOrder(orderId: string): Promise<ApiResponse<null>>
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `orderId` | `string` | Order ID to cancel |
