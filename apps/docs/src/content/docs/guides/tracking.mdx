---
title: Tracking
description: Track shipments by AWB or LRN
---

Track shipments using the `trackOrder` method. Pass the order ID to retrieve tracking status.

## Imports

```typescript
import {
  BigshipClient,
  isSuccessResponse,
} from '@agamya/bigship-sdk';
```

## Track by Order ID

```typescript
const tracking = await client.trackOrder('311276742');
if (isSuccessResponse(tracking)) {
  console.log('Status:', tracking.data.order_status);
  console.log('Tracking #: ', tracking.data.tracking_number);
  console.log('Courier:', tracking.data.courier_name);
}
```
